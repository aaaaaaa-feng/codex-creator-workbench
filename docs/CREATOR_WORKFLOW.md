# AI 内容创作者工作流与产品路线图

这份文档描述一个 AI 内容博主从“看到一个信号”到“形成可复用的方法”的完整过程，以及工作台应该怎样在每一步减少重复劳动。它既是产品设计依据，也是功能状态说明。

## 一条内容的完整生命周期

| 阶段 | 创作者真正要回答的问题 | 工作台当前能力 | 后续可增强能力 |
|---|---|---|---|
| 账号定位 | 我为谁讲、为什么值得听我讲？ | `AGENTS.md` 固化受众、语气与边界 | 可视化账号档案、内容支柱与禁用表达 |
| 信号采集 | 今天发生了什么？ | AIHOT 最新资讯、热榜、专题搜索 | 多来源订阅、去重聚类、趋势时间线 |
| 编辑筛选 | 哪条值得我讲？ | 五维评分、单行热点池、展开与多选 | 个性化相关度、选题配额、重复主题提醒 |
| 事实核验 | 哪些是事实、观点和推断？ | 原始来源、核验状态与风险边界 | 逐句证据卡、来源冲突提示、过期提醒 |
| 内容设计 | 用什么形式最适合？ | 口播稿、选题卡、镜头建议 | 内容类型选择器、教程模式、系列化规划 |
| 生产准备 | 拍摄或排版还缺什么？ | 标题、封面、镜头清单、文案归档 | 分镜板、提词器稿、字幕、素材任务清单 |
| 平台适配 | 同一事实怎样适配不同平台？ | 平台适配模板与自然语言改写 | 一键多平台内容包、并排预览、差异检查 |
| 人工发布 | 现在可以发了吗？ | 发布前检查与本地归档 | 平台草稿导出；任何真正发布仍需人工确认 |
| 数据复盘 | 什么值得继续，下一条只改什么？ | 真实数据台账与 72 小时复盘 | 自动图表、系列对比、可复用经验库 |
| 内容再利用 | 老内容能否形成新系列或产品？ | 可让 Codex 读取历史内容重新组合 | 语义素材库、选题防重复、跨平台再创作 |

## 视频类内容

### 口播与新闻解读

适合新模型、新产品、公司动作和行业变化。默认交付：

1. 3 个开场钩子。
2. 20–45 秒口播母稿。
3. 事实、观点与风险边界。
4. 真人、录屏和原文截图的镜头清单。
5. 标题、封面短句、发布文案和评论问题。

重点不是复述新闻，而是解释“这和目标观众有什么关系”，并保留创作者自己的判断。

### 教程与演示视频

教程不应只是操作录屏。完整内容包应包含：

1. 先展示真实结果。
2. 说明适合谁、前置条件和使用版本。
3. 把步骤、成功标志和常见失败放在一起。
4. 保留一个真实失败案例或限制。
5. 输出录屏清单、口播、屏幕文字、章节和可复现材料。

### 对比、测评与体验

所有对象使用同一任务、同一输入和同一评分标准。没有实际运行的项目必须标记为“待实测”，不能用预期结果代替证据。

## 图文类内容

图文不是把口播稿简单换行。工作台应先保留一份事实底稿，再根据阅读场景重组：

- 小红书：短段落、真实体验、图片页结构、首图短句和收藏价值。
- 公众号：上下文、导语、小标题、完整论证、来源与声明。
- B站：视频简介、章节、动态摘要、置顶评论和可复现材料。
- 抖音：强结果开场、口语节奏、画面动作、简短发布文案和评论问题。
- X：高密度单帖或线程，优先事实、观点、链接和可继续讨论的问题。

平台规则会变化，因此模板只固定创作逻辑，不把某个时期的字数或流量技巧写成永恒规则。

## 最值得优先完善的功能

### P0：直接减少每天重复劳动

- 内容类型选择器：口播、教程、对比、体验、图文、长文。
- 一键多平台内容包：共享事实底稿，分别生成小红书、抖音、B站、公众号和 X 版本。
- 版本比较与回滚：查看 Codex 改了什么，接受或恢复某一版。
- 教程视频生成器：结果、步骤、录屏、错误处理和可复现材料一次生成。
- 内容日历：把收件箱、待选题、制作中和已发布放到时间轴。

### P1：提升生产效率与一致性

- 分镜与素材看板：把每个镜头对应到待拍、待录屏、待找图和已完成。
- 提词器与字幕导出：从最终稿生成适合拍摄和剪辑的纯文本。
- 多平台并排预览：检查同一内容在不同平台是否只是机械复制。
- 事实证据卡：把关键句与来源绑定，修改时提示证据是否仍然支持。
- 系列化创作：从一条验证有效的内容生成 5 个不同故事，而不是 5 个近义标题。

### P2：发布、协作与增长闭环

- 平台草稿导出与发布前人工确认。
- 多人审稿、批注和角色权限。
- 真实数据导入、自动图表和内容系列对比。
- 素材版权、AI 生成标记和平台风险检查。
- 可插拔热点源、封面 Skill、字幕、剪辑和数据连接器。

## 必须保留的人类关口

工作台可以自动整理和生成，但以下决定不应默认自动化：

1. 最终选题。
2. 有争议事实的表达。
3. 是否采用某一版改稿。
4. 是否生成或使用人物封面。
5. 真正发布、评论、点赞或发送消息。
6. 对作品成败和下一步方向的最终判断。

AI 的价值是减少查找、整理、格式转换和重复改写；创作者的价值是经历、判断、审美和责任。

## 建议的验证节奏

方向不清楚时，先做小样本：强共鸣、真实反差、新鲜体验各 3 条。单条发布后观察约 72 小时，优先看收藏、有效评论、关注意愿和完播，而不是只看播放量。选出有效方向后，再围绕同一方法做不同故事的变体。
